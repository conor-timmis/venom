# Venom

Native desktop chat for people who watch and run livestreams across more than one platform.

Venom is a client that pulls **Twitch**, **Kick**, and **YouTube Live** into one customisable workspace. The planned build is in Rust with a Slint UI so it stays fast and light, the idea is to maintain high performance throughout.

**Who it's for:** streamers, moderators, and chat-focused viewers who want one native window instead of a pile of browser tabs.

**The target:** a daily-driver Windows 11 client (Linux next) with multi-column layouts, unified feeds, native and third-party emotes, filtering, highlighting, and moderation — all local-first, with no Venom-hosted accounts or cloud backend.

## Feature plan

- Multi-platform live chat (Twitch, YouTube Live, Kick)
- Unified and split workspaces, later multi-window
- Send, reply, and moderate where each platform allows
- Native emotes and badges, then 7TV, BetterTTV, and FrankerFaceZ
- Filters, highlights, optional local history
- Secure OAuth and OS credential storage
